# תוכנית המשימות

מסמך פנימי: תכנון המשימות לפני מימוש. הטקסט שהתלמיד רואה ייכתב בנפרד, קצר,
וללא כל התייחסות לתהליך הבנייה.

## עקרונות

1. **מעט מילים.** כל משימה מוצגת כלוח אינטראקטיבי שבו המטרה נראית לעין. אם צריך
   משפט הסבר, הוא שורה אחת.
2. **סולם עולה.** בתוך כל נושא, המשימות עולות בקושי ובידע הנדרש. המשימה הראשונה
   בכל נושא פתירה למי שסיים יסודי.
3. **רמזים מגשרים.** כל משימה נושאת סולם רמזים: רמז ראשון מסמן איפה להסתכל,
   השני מראה את הצעד הראשון, השלישי מבצע אותו על הלוח, והאחרון מדגים את הפתרון
   המלא צעד אחר צעד עם הסבר. הרמזים הם שמלמדים את החומר שחסר.
4. **הסבר גם בהצלחה.** אחרי פתרון נכון מוצג הסבר קצר של מה שעבד.
5. **וריאנטים.** כל משימה היא מחולל: אותו סוג חידה בנתונים אחרים בכל פתרון, כדי
   שאפשר יהיה לחזור עליה ולצבור כוכבים.

## מנוע המשימות

### מבנה הנתונים

```ts
type MissionKind =
  | 'numberline' | 'grid' | 'vectors' | 'alphametic' | 'powers'
  | 'angles' | 'triangle' | 'construction' | 'balance' | 'machine'
  | 'quest' | 'graph' | 'area' | 'pythagoras' | 'net' | 'chance'

interface MissionSpec {
  id: string
  topicId: string
  kind: MissionKind
  /** order within the topic; 1 is the easiest */
  level: number
  /** stars for a clean solve; fewer when hints were opened */
  reward: number
}

interface Variant<Config, Answer> {
  config: Config          // generated from a seed
  check: (answer: Answer) => boolean
  hints: Hint[]           // built from the same generated numbers
  explain: Step[]         // shown after a correct answer
}
```

### כוכבים

פתרון נקי שווה את מלוא הכוכבים של המשימה; כל רמז שנפתח מוריד אחד, ולא מתחת
לכוכב אחד. וריאנט חוזר של משימה שכבר נפתרה שווה מחצית.

## פירוט המנה הראשונה

### משימה 1 — אוצר על הציר

**תיאור.** ציר מספרים אופקי עם סימונים. על הציר מסומן יעד בדגל. התלמיד גורר
תיבת אוצר על הציר ומשחרר במקום היעד. בשלבים מתקדמים הסימון דליל יותר, היעד
שלילי, והציר מתחיל במספר שאינו אפס.

**דרישות פיתוח.** `board/NumberLine`: ציר עם טווח, צפיפות סימון, תוויות, גרירה
עם הצמדה לסימון הקרוב; מחולל שמגריל טווח, צפיפות ויעד לפי הדרגה; בדיקה
שהמיקום שווה ליעד.

**רמזים.**
1. התוויות שמשני צדי היעד מודגשות.
2. כמה יחידות יש בין שני סימונים גדולים — מסומן על הציר.
3. הציר ממוספר צעד־צעד מהסימון הקרוב עד היעד.
4. האוצר נע לבד אל היעד לאורך הציר, ולצידו הספירה.

**הסבר אחרי הצלחה.** המרחק בין שני סימונים גדולים, ומה זה אומר על כל סימון קטן.

**בדיקות.** מחולל: לכל זרע, היעד נמצא בתוך הטווח ועל סימון; בדיקה: רק המיקום
הנכון מתקבל; סטייה של סימון אחד נדחית. בדפדפן: גרירה ליעד מסיימת בהצלחה,
גרירה למקום אחר לא, פתיחת רמז מורידה כוכב, הסבר מוצג.

### משימה 2 — קפיצות

**תיאור.** צפרדע על ציר המספרים ויעד. למטה מוצגים חצים: `+5`, `−3` וכדומה, כל
אחד בכמה עותקים. התלמיד גורר חצים לרצף, והצפרדע קופצת בהתאם בזמן אמת.

**דרישות פיתוח.** הרחבת `board/NumberLine` בקפיצות מונפשות; מגש חצים עם גרירה;
מחולל שבונה יעד שניתן להשגה בדיוק ברצף קיים; בדיקה שהסכום מגיע ליעד.

**רמזים.**
1. היעד והמיקום הנוכחי מסומנים יחד עם המרחק ביניהם.
2. מוצג סכום החצים שנבחרו עד כה מול המרחק הנדרש.
3. החץ הראשון של הפתרון נכנס לרצף.
4. הרצף כולו נבנה, קפיצה אחרי קפיצה, עם הסכום המצטבר.

**הסבר אחרי הצלחה.** חיבור של חץ ימינה ושל חץ שמאלה, וכיצד הם מבטלים זה את זה.

**בדיקות.** מחולל: קיים רצף פותר; בדיקה: רק סכום היעד מתקבל; אין תלות בסדר.
בדפדפן: גרירת חצים מזיזה את הצפרדע, רצף נכון מסיים בהצלחה.

### משימה 3 — מסע הספינה

**תיאור.** סדרת חצים נתונה מראש מעל הציר. התלמיד מסמן על הציר את נקודת הסיום.

**דרישות פיתוח.** אותו לוח; מצב "קריאה" לחצים נתונים; מחולל שמגריל אורכי חצים
וסימנים; בדיקה מול הסכום.

**רמזים.** 1. החץ הראשון מודגש. 2. הספינה זזה לפי החץ הראשון בלבד. 3. שני
החצים הראשונים מבוצעים. 4. כל החצים מבוצעים אחד אחרי השני עם הסכום המצטבר.

**הסבר אחרי הצלחה.** סכום של מספרים מכוונים הוא שרשרת צעדים על הציר.

**בדיקות.** כמו למעלה, ובנוסף: רצף שסכומו שווה אך בסדר אחר מגיע לאותה תוצאה.

### משימה 4 — האוצר ברביע

**תיאור.** לוח עם ארבעה רביעים. שתי דמויות על הלוח, כל אחת מראה רמיזה
גרפית — האחת מסמנת עמודה, השנייה שורה. התלמיד מסמן את מקום האוצר.

**דרישות פיתוח.** `board/Grid`: רשת, צירים, סימון נקודה בלחיצה, תוויות; מחולל
רמיזות; בדיקה מול הנקודה.

**רמזים.** 1. הרמיזה הראשונה מצוירת כקו על הלוח. 2. גם השנייה. 3. החיתוך מהבהב.
4. הנקודה מסומנת ומוצגת כזוג מספרים.

**הסבר אחרי הצלחה.** הסימן של כל קואורדינטה והרביע שבו היא נופלת.

**בדיקות.** מחולל: הנקודה בתוך הלוח ולא על הצירים; בדיקה: רק הנקודה הנכונה.
בדפדפן: לחיצה מסמנת, בדיקה מצליחה.

### משימה 5 — מראה

**תיאור.** צורה על הרשת וציר מסומן. התלמיד גורר עותק של הצורה למקום המשוקף.

**דרישות פיתוח.** גרירת צורה על הרשת עם הצמדה; חישוב שיקוף; בדיקת התאמה מדויקת.

**רמזים.** 1. הציר מודגש. 2. קודקוד אחד של הצורה והמרחק שלו מהציר מסומנים.
3. אותו קודקוד מוצב במקומו המשוקף. 4. כל הקודקודים עוברים אחד אחרי השני.

**הסבר אחרי הצלחה.** מה משתנה בכל קואורדינטה בשיקוף סביב כל אחד מהצירים.

**בדיקות.** מחולל: הצורה אינה סימטרית ביחס לציר; בדיקה: רק המיקום המשוקף
מתקבל; הזזה ללא שיקוף נדחית.

## מצב המימוש

כל שלושים ואחת המשימות מומשו, יחד עם מנוע המשימות, סולם הרמזים, ההסברים
וכלכלת הכוכבים. סולם המבצרים כוון מחדש לכמות הכוכבים שהמשימות משלמות.

## החלטות שהוכרעו

1. **מנוע חיצוני לזוויות ולגרפים, או רכיבים משלנו.** רכיבים משלנו שומרים על
   אתר סטטי בלי תלות חיצונית ועל סגנון אחיד; מנוע חיצוני חוסך פיתוח אבל מוסיף
   טעינה מרשת זרה.
2. **כמה כוכבים שווה משימה.** הסולם הנוכחי דורש כ‑1250 כוכבים לכיבוש כל
   היבשות. בשלוש עד חמש כוכבים למשימה זה כ‑300 פתרונות לאורך שנה.
3. **סדר המימוש.** המנה הראשונה היא אסיה; אחריה אוסטרליה ואפריקה.
